# YouTube Lecture Transcriber (`whisper.cpp`)

Оптимизированный Bash-пайплайн для скачивания, фильтрации и локальной транскрибации лекций с YouTube в чистый текстовый файл `.txt`.

Скрипт решает главные проблемы длинных академических записей: зависание модели на тишине, бесконечные зацикливания, а также известные галлюцинации русскоязычной модели Whisper (например, появление фантомных подписей вроде *«Субтитры создавал DimaTorzok»*).

---

## ⚡ Ключевые возможности и защита от артефактов

### 1. Борьба с фантомными субтитрами («DimaTorzok» и тишина)
В оригинальном датасете Whisper содержатся тысячи роликов с подписями переводчиков. При распознавании пауз, музыки или неразборчивого шума модель склонна додумывать шаблоны вроде *«Субтитры создавал...»*, *«Аплодисменты»* или *«Продолжение следует»*. 

В данном пайплайне эта проблема решается комплексно на трех уровнях:
- **Аппаратная VAD-фильтрация звука в `ffmpeg`:** фильтр `silenceremove` удаляет длинные паузы и участки без звука еще до отправки в нейросеть.
- **Тюнинг гиперпараметров `whisper-cli`:**
  - `--max-context 0`: полностью запрещает переносить контекст предыдущих фраз (устраняет бесконечные зацикливания).
  - `--prompt "..."`: задает стартовый контекст научного доклада, исключая переход в режим «титров».
  - `--no-speech-thold 0.7` и `--logprob-thold -0.8`: ужесточают порог детекции тишины и отсекают сомнительные гипотезы.
  - `--entropy-thold 2.4`: отфильтровывает повторяющийся бред с низкой энтропией.
  - `--suppress-nst`: подавляет неречевые служебные токены.
- **Автоматическая посточистка через `sed`/`awk`:** удаляет любые остаточные артефакты титров и лишние пустые строки.

### 2. Прямая конвертация без лишнего перекодирования
`yt-dlp` захватывает аудиопоток и сразу отдает его через `ffmpeg` в нативный для Whisper формат **16-bit Mono PCM 16 kHz**, минуя промежуточный MP3 с потерями.

### 3. Автономная временная среда
Все промежуточные файлы (`.wav`, дампы) изолированы во временной системной папке (`mktemp -d`). Команда `trap` гарантирует удаление гигабайтов мусора с диска даже при ручной остановке процесса (`Ctrl+C`). На выходе остается только итоговый файл `.txt`.

## 📦 Установка зависимостей

### macOS (Apple Silicon / Intel)
```bash
brew install yt-dlp ffmpeg whisper-cpp
```

### Linux (Ubuntu / Debian)
```bash
sudo apt update && sudo apt install ffmpeg curl git make g++
# Актуальная версия yt-dlp
sudo curl -L https://github.com/yt-dlp/yt-dlp/releases/latest/download/yt-dlp -o /usr/local/bin/yt-dlp
sudo chmod a+rx /usr/local/bin/yt-dlp

# Сборка whisper.cpp
git clone https://github.com/ggml-org/whisper.cpp.git
cd whisper.cpp && make
sudo cp build/bin/whisper-cli /usr/local/bin/
```

## 🧠 Загрузка модели Whisper

Для академических лекций и точного распознавания русской терминологии рекомендуется модель **Large-v3** (или облегченная **Large-v3-Turbo**):

```bash
# Модель Large-v3 (~3.1 GB) — эталонное качество:
curl -L -O https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-large-v3.bin

# Модель Large-v3-Turbo (~1.6 GB) — в 2 раза быстрее при минимальной потере качества:
curl -L -O https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-large-v3-turbo.bin
```

## 🚀 Использование

1. Сделайте скрипт исполняемым:
   ```bash
   chmod +x transcribe.sh
   ```

2. Запустите транскрибацию (ссылку обязательно берите в **двойные кавычки**, чтобы `zsh` не ругался на спецсимволы `?` и `&`):
   ```bash
   ./transcribe.sh "https://www.youtube.com/watch?v=dQw4w9WgXcQ" "quantum_mechanics_lec01"
   ```

3. В текущей директории будет сформирован чистый текст:
   ```text
   quantum_mechanics_lec01.txt
   ```

## ⚙️ Переменные окружения

Скрипт гибко конфигурируется через переменные без редактирования кода:

| Переменная | По умолчанию | Описание |
| :--- | :--- | :--- |
| `WHISPER_MODEL` | `ggml-large-v3.bin` | Путь к бинарному файлу модели |
| `WHISPER_BIN` | `/opt/homebrew/bin/whisper-cli` | Путь к бинарнику `whisper-cli` |
| `LANGUAGE` | `ru` | Язык аудио (`ru`, `en`, `auto` и др.) |

### Примеры:

```bash
# Транскрибация англоязычной лекции
LANGUAGE="en" ./transcribe.sh "https://youtu.be/..." "lecture_en"

# Использование модели Turbo на Linux
WHISPER_MODEL="ggml-large-v3-turbo.bin" WHISPER_BIN="/usr/local/bin/whisper-cli" ./transcribe.sh "URL"
```

## 🤖 Саммаризация результата через LLM

Полученный файл `.txt` можно сразу отправить в LLM для формирования конспекта. Пример эффективного промпта:

```text
Сделай структурированный академический конспект лекции по следующей расшифровке:
1. Выдели ключевые темы, тезисы и логику повествования.
2. Сохрани все упомянутые определения, фамилии, даты и формулы.
3. Оформи результат в формате Markdown с удобными списками и акцентами.

Текст расшифровки:
[ВСТАВИТЬ СОДЕРЖИМОЕ .TXT]
```
