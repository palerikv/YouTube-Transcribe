# YouTube Lecture Transcriber (`whisper.cpp`)

Автоматизированный CLI-инструмент на Bash для скачивания, обработки и офлайн-транскрибации русскоязычных видео/лекций с YouTube в чистый текстовый файл `.txt`.

Скрипт решает главные проблемы длинных академических записей: зависание модели на тишине, бесконечные циклы повторения одних и тех же фраз и накопление промежуточного мусора на диске.

Для использования необходим подключенный VPN!
---

## 💡 Архитектура и технические решения

Транскрибация длинных лекций с помощью стандартных параметров Whisper часто приводит к дефектам. В скрипте применен ряд оптимизаций для предотвращения сбоев:

### 1. Предотвращение зацикливаний и галлюцинаций
- `--max-context 0`: полностью отключает влияние текста предыдущего сегмента на генерацию следующего. Это исключает бесконечные повторы одной фразы при паузах лектора.
- `--no-speech-thold 0.6` и `--logprob-thold -1.0`: фильтруют тишину, вздохи и фоновый шум аудитории, не позволяя декодеру выдумывать несуществующие слова.
- `--entropy-thold 2.6`: отсекает сегменты с аномально низкой или высокой энтропией, предотвращая спам повторяющимися токенами.
- `--suppress-nst`: подавляет неречевые токены (аплодисменты, музыку, спецсимволы).

### 2. Прямая конвертация без потерь и двойного кодирования
Обычно связка `yt-dlp` + `whisper` скачивает MP3, а затем перекодирует его в WAV. Здесь `yt-dlp` передает поток напрямую через постобработчик `ffmpeg` в несжатый **16-bit Mono PCM 16 kHz**, который является нативным входным форматом для `whisper.cpp`.

### 3. Чистое дисковое пространство
Все промежуточные файлы (`.wav`, служебные дампы) создаются в системной временной директории (`mktemp -d`). Команда `trap 'rm -rf "$TMP_DIR"' EXIT` гарантирует удаление гигабайтов временных данных даже при принудительном завершении процесса (`Ctrl+C`) или ошибке сети.

## 🛠 Зависимости и окружение

Скрипт оптимизирован для работы на macOS (Apple Silicon / Intel) и Linux.

### Необходимый софт:
- `yt-dlp` — загрузка потоков YouTube с обходом троттлинга.
- `ffmpeg` — процессинг аудио.
- `whisper-cli` — C/C++ инференс моделей OpenAI Whisper.

### 1. Установка утилит

**macOS (Homebrew):**
```bash
brew install yt-dlp ffmpeg whisper-cpp
```

**Ubuntu / Debian:**
```bash
sudo apt update && sudo apt install ffmpeg curl
# Установка актуальной версии yt-dlp
sudo curl -L https://github.com/yt-dlp/yt-dlp/releases/latest/download/yt-dlp -o /usr/local/bin/yt-dlp
sudo chmod a+rx /usr/local/bin/yt-dlp

# Сборка whisper.cpp
git clone https://github.com/ggml-org/whisper.cpp.git
cd whisper.cpp && make
sudo cp build/bin/whisper-cli /usr/local/bin/
```

### 2. Загрузка весов модели

Для качественного распознавания русской терминологии рекомендуется модель **Large-v3** (или **Large-v3-Turbo**):

```bash
# Large-v3 (~3.1 GB) — максимальное качество
curl -L -O https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-large-v3.bin

# Либо Large-v3-Turbo (~1.6 GB) — высокая скорость при минимальной потере качества
curl -L -O https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-large-v3-turbo.bin
```

## 🚀 Использование

### Быстрый старт

1. Сделайте скрипт исполняемым:
   ```bash
   chmod +x transcribe.sh
   ```

2. Запустите процесс, указав ссылку на видео и желаемое имя файла:
   ```bash
   ./transcribe.sh "https://www.youtube.com/watch?v=dQw4w9WgXcQ" "quantum_mechanics_lec01"
   ```

3. По завершении в текущей директории появится файл:
   ```text
   quantum_mechanics_lec01.txt
   ```

## ⚙️ Настройка через переменные окружения

Скрипт не требует правки кода для изменения путей или моделей:

| Переменная | По умолчанию | Описание |
| :--- | :--- | :--- |
| `WHISPER_MODEL` | `ggml-large-v3.bin` | Путь к бинарному файлу модели |
| `WHISPER_BIN` | `/opt/homebrew/bin/whisper-cli` | Путь к исполняемому файлу `whisper-cli` |

### Примеры:

```bash
# Использование другой модели
WHISPER_MODEL="./models/ggml-large-v3-turbo.bin" ./transcribe.sh "URL" "lecture"

# Запуск на Linux (если бинарник лежит в /usr/local/bin)
WHISPER_BIN="/usr/local/bin/whisper-cli" ./transcribe.sh "URL" "lecture"
```

## 📊 Рекомендации по дальнейшей обработке текста

Полученный файл `lecture.txt` содержит чистую расшифровку речи. Для превращения его в структурированный конспект передайте текст в любую LLM со следующим промптом:

```text
Сделай структурированный конспект лекции по следующей расшифровке:
1. Выдели ключевые тезисы и структуру повествования.
2. Сохрани все определения, имена ученых, даты и формулы.
3. Убери речевой мусор, повторы и оговорки спикера.

Текст расшифровки:
[ВСТАВИТЬ СОДЕРЖИМОЕ .TXT]
```
